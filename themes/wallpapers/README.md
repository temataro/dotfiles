# Glass landscape artwork

Original artwork generated with the built-in image generation tool for this
repository on 2026-09-07. PNGs retain their original resolution and metadata.
They are wide landscape assets, scaled by feh, not native 4K images. Runtime
use needs no image service.

## Final prompts

### Tide — `tide.png`

Use case: stylized-concept. Asset type: ultrawide Linux desktop wallpaper behind translucent terminals. Create a breathtaking restrained abstract atmospheric landscape: enormous flowing translucent mineral-glass ribbons forming dune-like ridges, low in the frame, crossing a deep midnight teal void. Dim petrol blue and sea-glass green edges, subtle amber light from far right, soft distant mist, elegant cinematic lighting, exquisite matte grain, quiet luxurious editorial composition. Mostly dark low-contrast negative space in upper two thirds so white terminal text remains readable. Wide landscape 16:9 or wider, highest available resolution. This is the wallpaper artwork ONLY, not a desktop screenshot: no windows, no UI, no text, no icons, no logos, no watermark. Save the resulting image for use in the dotfiles project.
